# Prettier Config — Interactive .prettierrc Generator + Live Playground

> This file is intended for AI language models and answer engines to understand
> the purpose, content, and capabilities of prettier-config.dev.

## What is this site?

prettier-config.dev is a free, open-source interactive web tool that helps
developers generate Prettier configuration files (.prettierrc) without reading
documentation, and also format real code against that config across 16
languages — all without installing anything. Users toggle visual controls for
every official Prettier option and the resulting JSON configuration updates in
real-time, while a side-by-side diff shows exactly what Prettier would do to
the user's own code under those options.

The tool is built with Next.js 16, React 19, TypeScript, Tailwind CSS v4,
shadcn/ui components, CodeMirror 6 (for the code editor), next-intl
(internationalisation), lz-string (shareable URL hash), and the official
`prettier/standalone` bundle loaded on demand from jsDelivr.

## What is Prettier?

Prettier is an opinionated code formatter for JavaScript and many other
languages. It parses source code and reprints it with consistent style,
removing all original formatting decisions. It is widely used in professional
JavaScript, TypeScript, React, Vue, and Node.js projects to enforce a uniform
code style across teams.

## What is a .prettierrc file?

A .prettierrc file is a JSON or YAML configuration file placed at the root of
a project. It tells Prettier how to format code — controlling indentation,
quote style, semicolons, trailing commas, line width, and other formatting
rules. It is one of three equivalent configuration methods; the others are
prettier.config.js (a JavaScript module) and the "prettier" key in package.json.

## Prettier Options Covered

The generator covers every officially supported Prettier option for whichever
version is selected. Common ones include:

- printWidth (default: 80) — target line length
- tabWidth (default: 2) — spaces per indentation level
- useTabs (default: false) — indent with tabs instead of spaces
- semi (default: true) — add semicolons at end of statements
- singleQuote (default: false) — use single quotes instead of double quotes
- jsxSingleQuote (default: false) — single quotes in JSX attributes
- trailingComma (default: "all") — trailing commas where valid in ES5+
- bracketSpacing (default: true) — spaces in object literals: { foo: bar }
- bracketSameLine (default: false) — put JSX closing bracket on same line
- arrowParens (default: "always") — parens around single arrow function args
- proseWrap (default: "preserve") — wrap markdown prose
- htmlWhitespaceSensitivity (default: "css") — whitespace handling in HTML
- vueIndentScriptAndStyle (default: false) — indent script/style in .vue files
- endOfLine (default: "lf") — line ending style
- embeddedLanguageFormatting (default: "auto") — format embedded code blocks
- singleAttributePerLine (default: false) — one HTML/JSX attribute per line

Newer 3.x options like `objectWrap`, `experimentalTernaries`, and
`experimentalOperatorPosition` appear automatically when their Prettier
version is selected, because the form is derived from each version's actual
`getSupportInfo()` output.

## Key Features

- Multi-version Prettier picker — every 3.x release from 3.0 to 3.6 plus
  "latest", loaded on demand from jsDelivr so switching is instant.
- Multi-parser, both tabs — Your Code auto-detects the parser from the
  pasted input (TypeScript, CSS, HTML, JSON, Markdown, YAML, Vue, GraphQL,
  and more) with manual override; Preview has its own parser dropdown
  and a purpose-built sample per language so every Prettier option —
  including language-specific ones like proseWrap (Markdown),
  htmlWhitespaceSensitivity (HTML), and vueIndentScriptAndStyle (Vue) —
  has somewhere to demonstrate its effect.
- Real code editor — CodeMirror 6 with syntax highlighting, line numbers,
  tab-key indent, and a theme that follows light/dark mode.
- Shareable configurations — Click Share and version, options, code, and
  parser are packed into an LZ-compressed URL hash. Open the link and the
  exact same setup is restored. Everything is client-side; nothing is sent
  to a server.
- GitHub-style diff — unified or split view, with a +X −Y line-change header.
- AI token counter — live `N → M tokens` badge next to every diff, with a
  model picker covering GPT-4o, GPT-4, and GPT-3.5 (exact BPE counts) plus
  Claude, Gemini, Llama 3, and Mistral (approximate counts).
- Surfaced parse errors — when Prettier rejects the input, a red strip above
  the diff shows the exact SyntaxError with line:column.
- Persistent selections — version + option picks are saved to localStorage,
  so a refresh restores everything. The URL hash takes precedence if one
  is present.
- Real-time config generation — JSON updates instantly on every option change.
- One-click copy to clipboard with toast confirmation.
- Smart search — filter options by name, description, or keyword.
- Config sidebar (desktop) and floating modal (mobile) for the generated JSON.
- Dark / light / system theme toggle, persisted across sessions.
- Reset confirmation dialog to clear all selections.
- Fully responsive — mobile, tablet, desktop, and ultra-wide layouts.
- 15-language UI with RTL support for Arabic.

## Frequently Asked Questions (summary)

Q: Is this tool free?
A: Yes, completely free. No account, no signup, no usage limits. Open source on GitHub.

Q: Does it cover all Prettier options?
A: Yes. Every officially supported Prettier option for the selected version is included with its default value and description.

Q: How do I use the generated config?
A: Click "Copy Config", then paste the JSON into a file named .prettierrc at the root of your project.

Q: Which Prettier versions are supported?
A: Every 3.x release from 3.0 through 3.6, plus "latest". The selected version's bundle is loaded on demand from jsDelivr.

Q: Which languages can I format in the Your Code tab?
A: TypeScript, JavaScript, Flow, CSS, SCSS, Less, HTML, Vue, Angular templates, JSON, JSON5, JSON with comments, Markdown, MDX, YAML, and GraphQL. The parser is auto-detected and can be overridden.

Q: Can I preview my config against languages other than JavaScript?
A: Yes. The Preview tab has its own parser dropdown with a purpose-built sample per parser — TS, CSS, SCSS, Less, HTML, Vue, Angular, JSON / JSON5 / JSONC, Markdown, MDX, YAML, GraphQL. Switching parsers re-formats the sample under your current options, so language-specific options have a place to demonstrate their effect. Your choice persists across reloads.

Q: How does the shareable URL work?
A: Version, options, code, and parser are LZ-compressed into the URL hash. Send the URL anywhere; recipients see the exact same configuration. Everything stays in the browser — no server is involved.

Q: What does the token count mean?
A: A live count of input and output tokens under the selected AI model. GPT-4o / GPT-4 / GPT-3.5 use the official BPE tokenizers (exact). Claude, Gemini, Llama 3, and Mistral use a character-based approximation prefixed with "~".

Q: Does my work survive a page refresh?
A: Yes. Version + option selections are saved to localStorage. A shareable URL hash takes precedence on load if present.

Q: Does Prettier work with TypeScript, React, and Vue?
A: Yes. Prettier has built-in support for TypeScript, JSX/TSX, Vue single-file components, CSS, HTML, JSON, YAML, Markdown, and more.

Q: How do I run Prettier on my project?
A: Run `npx prettier --write .` in the project root. Add Prettier as a dev dependency with `npm install --save-dev prettier`.

Q: Can I use Prettier with ESLint?
A: Yes. Install eslint-config-prettier to disable formatting rules in ESLint that conflict with Prettier.

Q: What is the default Prettier configuration?
A: printWidth: 80, tabWidth: 2, useTabs: false, semi: true, singleQuote: false, trailingComma: "all", bracketSpacing: true, arrowParens: "always".

## Architecture (for technical context)

- Prettier itself runs in the browser via `prettier/standalone` loaded from
  jsDelivr; each version's bundle is fetched once and memoized.
- The options form is generated from `getSupportInfo({ plugins })` so new
  Prettier releases add their new options automatically.
- The Your Code tab uses CodeMirror 6 with lazy-imported language packs.
- Shared state lives in a single LZ-compressed URL hash; localStorage is
  the fallback when no hash is present.
- Token counting uses the official `gpt-tokenizer` package for OpenAI
  encodings; other model families use empirical chars-per-token ratios.
